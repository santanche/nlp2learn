PROTOCELL-0 LANGUAGE LABS

How embeddings form

Protocell-0 is an invented organism with an invented genetic code. Its genome is a text whose grammar we wrote, so we know exactly what a model should be able to learn from it. These labs follow two kinds of word representation: static embeddings (one vector per codon type) and contextual embeddings (one vector per codon occurrence).
